I built the website for my IP studio **LokiFRAK** (PanelFRAK on the live brand). It lists the studio’s works and includes a blog — without a traditional database backend.

## Approach

- **Hugo** static site generation for speed, portability, and simple content workflows
- Featured worlds carousel, works archive, and theme-aware chrome
- Cyberpunk / night-city visual language aligned with the studio’s fiction

See it live at [comics.lokifrak.com](https://comics.lokifrak.com).
